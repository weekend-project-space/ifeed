# iFeed

iFeed 是一个帮助你整理和阅读互联网内容的应用。

它可以把你关心的信息集中到一起，用 AI 帮你过滤重复和低质量内容，让你更快看到真正有用的信息。

## 你可以用它做什么

- **订阅网站**：添加支持 RSS 的网站，文章更新后会自动收集到 iFeed。
- **发现内容**：浏览推荐内容，也可以按关键词搜索文章。
- **专心阅读**：在一个地方阅读不同网站的文章，减少来回切换。
- **记录进度**：自动保存阅读历史，并记录哪些内容已经读过。
- **喜欢和收藏**：给喜欢的文章点喜欢，也可以收藏到自己的文件夹里。
- **智能整理**：AI 可以生成摘要、分类和标签，帮助你快速判断文章是否值得阅读。

## 内容是怎么到你的面前的

1. iFeed 定期检查你订阅的网站是否有新文章。
2. 系统会清理网页中的广告和无关内容，并整理文章信息。
3. AI 会帮助识别文章主题、生成摘要和判断内容质量。
4. 文章会出现在你的订阅列表、搜索结果或推荐内容中。

你的喜欢、收藏和阅读记录会帮助系统逐渐了解你的兴趣，但这些操作不会改变原网站的内容。

## 项目组成

项目由几个相互配合的部分组成，普通使用者不需要分别操作它们：

- `ifeed-app`：启动整个应用，并提供网页和接口。
- `ifeed-identity`：处理注册、登录和账号安全。
- `ifeed-content`：保存网站、文章和文章详情。
- `ifeed-subscription`：管理你订阅的网站。
- `ifeed-user-engagement`：保存阅读历史、喜欢和收藏。
- `ifeed-ingestion`：定期从网站获取新文章。
- `ifeed-intelligence`：提供搜索、推荐和 AI 整理能力。
