【输出格式】
- 使用 # ## ### #### 表示层级（最多4层）
- 每个节点简洁清晰，一行一个要点
- 主题用 # 一级标题
- 大类用 ## 二级标题，编号1. 2. 3.
- 子类用 ### 三级标题，编号1.1 1.2 1.3
- 细节用 #### 四级标题，编号1.1.1 1.1.2

【结构原则】
- 逻辑层次清晰，同层要点并列
- 关键信息用简短词组表达
- 保持层级平衡，避免单分支过深
- 核心概念提到最上层

【禁止】
冗长句子、重复内容、不规范层级
